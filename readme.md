# SCALE-MALL

Infos and Screenshots for the **Dyson Sphere Program** `SCALE-MALL`.

> This Mall will **SCALE** as you do.
>
![Overview](pictures/SCALE-Mall Total.jpg)   

## Overview

The Mall is very **optimised** (but not compact — at least not yet). If you have power shortages (*brown-out*) or even a power fail (*blackout*), it will still work flawlessly. That is the downside of many Sushi-Belt-Malls.

- Power is **only** needed for Assemblers, Logistic Distributors / PLS / ILS (and of course Spray Coaters).
- The **feeding system is totally power-free!**

## Blueprints

- All Blueprints work perfectly for **< 900 Items** (except the ILS-Add to the Mall, which is a little above) — so it works with **Red-Tech Mass Construction Lv 3!**
- They join together with specific joint-steps.
- I add Screenshots to visualise how to. I prefer to build the Mall with an **empty Inventory**, to prevent unwanted collides (looking at you, Tesla Towers!).

## Foundation Colors

I added colours to the Foundations, so you can see it from **Space** and figure out which Building will be where (organised by **Cube-Colors** to unlock specific items).

> ⚠️ Check the custom colors below — they need to be set in your game for the custom foundation colors.

## Custom Assemblers

I added **10 Assemblers** without a recipe, so you can add whatever item you like. Just be aware of the needed Input. I rounded up the demand numbers on the Feeder-Part — if you exceed this, it will take longer to saturate.

## Feeding the Mall

There are different approaches to feed this Mall, as each player has a unique playstyle. I added a **PLS** and an **ILS-Feeder System** for the intermediate Products.

> ⚠️ If you **don't** place the `MALL-ILS`, the Assemblers that need Buildings (e.g. Tesla Tower for Wireless Power Tower) **won't** get the corresponding item — unless you work around it!

## Downsides

- As every Sushi-Mall, the SCALE Mall needs a **few Minutes to saturate**. But the way it does prefers the **low-Tech Buildings first**, as they tend to be used more often.
- The **Initial Setup is BELT-Heavy**. To start working properly you need at least:
  - `2330` Mk1 Belts
  - `12` Mk2 Belts
  - `3130` Mk3 Belts *(can be downgraded in early game! But be careful when upgrading them later!)*
- I **excluded Sorters and Belts** — they are so much needed that a dedicated build for them is easier. You *could* add them, but I recommend keeping them out of this one.
